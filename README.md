## TP1 — Fouille de données (Data Mining)
# Description
Ce TP porte sur l'exploration et la préparation de jeux de données avec Python, Pandas, Scikit-learn et Jupyter Notebook dans l'environnement Anaconda.

L'objectif est de transformer des données brutes en informations exploitables en apprenant à :
- Charger et explorer différents jeux de données (.csv et .arff).
- Identifier le nombre d'instances, les attributs et leurs types.
- Calculer les statistiques descriptives : minimum, maximum, médiane, quartiles, mode et moyenne.
- Visualiser les données avec des boxplots et des scatter plots.
- Détecter et traiter les valeurs manquantes.
- Normaliser les données avec Min-Max et Z-score.
# Contenu
- TP1_HADBI_HALI.ipynb : notebook du TP.
- Fichiers .csv et .arff : jeux de données (benchmarks) utilisés pendant les exercices.
# Environnement
- Python 3
- Anaconda / Jupyter Notebook
- Pandas
- Scikit-learn
- Matplotlib (pour les visualisations)
# Exécution
1. Ouvrir Anaconda Navigator ou Anaconda Prompt.
2. Lancer Jupyter Notebook.
3. Ouvrir TP1_HADBI_HALI.ipynb.
4. Exécuter les cellules dans l'ordre.
